# Glimmer — website

Landing page for **Glimmer**, a macOS menu-bar app that puts live weather on your desktop:
snow that piles up on your windows and Dock, rain, sakura, leaves, fireflies and starfall.

Static site (HTML + CSS + a little JS), published with GitHub Pages.

- `index.html` — the page
- `assets/style.css`, `assets/main.js` — styles and snow animation
- `assets/img/` — wallpapers, menu screenshots, app icon

The demo video goes into the "See it in action" block — see the `VIDEO PLACEHOLDER` comment in `index.html`.
